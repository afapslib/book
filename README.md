# ระบบเสนอความต้องการหนังสือ — ห้องสมุด กสป.รร.ตท.สปท.

เว็บแอป Google Apps Script สำหรับให้หน่วยงานเสนอรายชื่อหนังสือที่ต้องการให้ห้องสมุดจัดหา รองรับมือถือและคอมพิวเตอร์ และเพิ่มรายการหนังสือได้หลายรายการในหนึ่งคำขอ

## โครงสร้างไฟล์
- `Code.gs` — ฝั่งเซิร์ฟเวอร์ ตรวจสอบข้อมูลและบันทึกลง Google Sheets
- `Index.html` — หน้าเว็บ Responsive โทนสีม่วงอ่อน พร้อมภาพประกอบหนังสือแบบ SVG
- `appsscript.json` — การตั้งค่า Apps Script

## วิธีติดตั้ง (แนะนำ: GitHub + clasp)

1. สร้าง Repository ใหม่บน GitHub และอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. ติดตั้ง Node.js และ clasp:
   ```bash
   npm install -g @google/clasp
   clasp login
   ```
3. สร้างโปรเจกต์ Apps Script ใหม่ที่ `https://script.google.com/`
4. คัดลอก Script ID จาก Project Settings แล้วเชื่อมโฟลเดอร์ในเครื่อง:
   ```bash
   clasp clone YOUR_SCRIPT_ID
   ```
5. นำ `Code.gs`, `Index.html` และ `appsscript.json` จาก GitHub มาไว้ในโฟลเดอร์โปรเจกต์ (ไฟล์ HTML ใน Apps Script ต้องมีชื่อ `Index`)
6. ส่งโค้ดขึ้น Apps Script:
   ```bash
   clasp push
   ```
7. ใน Apps Script เลือก **Deploy > New deployment > Web app**
   - Execute as: **Me**
   - Who has access: เลือกตามนโยบายของหน่วยงาน (เช่น Anyone within your organization หากใช้ Google Workspace)
8. กด Deploy และอนุญาตสิทธิ์เข้าถึง Google Sheets เมื่อระบบร้องขอ จากนั้นนำ URL ที่ได้ไปใช้งาน

## ข้อควรตรวจสอบก่อนเปิดใช้งาน
- บัญชี Google ที่ Deploy ต้องมีสิทธิ์แก้ไข Spreadsheet ดังกล่าว
- ตรวจสอบการตั้งค่าผู้มีสิทธิ์เข้าถึง Web app ให้เหมาะสมกับข้อมูลภายในหน่วยงาน
- หากมีชีท `book` อยู่ก่อนแล้ว ระบบคาดว่าหัวตารางแถวแรกจะเริ่มด้วย `วันที่เสนอ` และ `รหัสคำขอ` หากเป็นชีทเดิมที่มีข้อมูลอยู่ ควรสำรองข้อมูลและจัดหัวตารางให้ตรงก่อน
- เมื่อแก้ไขโค้ดหลัง Deploy ให้เลือก **Deploy > Manage deployments > Edit > New version** เพื่อเผยแพร่เวอร์ชันใหม่

4. กดเพิ่มรายการเพื่อทดสอบการเสนอหลายเล่ม
5. ส่งข้อมูล แล้วตรวจสอบแถวใหม่ในชีท `book`
